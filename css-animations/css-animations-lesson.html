CSS Animations: Interactive Lesson

An animation has two parts: @keyframes (what changes) and the animation properties (how it plays). Press Replay on each demo.

1. @keyframes + name + duration

The minimum you need: a name and a duration.

@keyframes slide {
  from { transform: translateX(0); }
  to   { transform: translateX(220px); }
}

.box {
  animation-name: slide;
  animation-duration: 2s;
}

2. animation-timing-function

Same distance and time, different speed curve. Watch who is fastest at the start and the end.

animation-timing-function: linear;
animation-timing-function: ease;      /* default */
animation-timing-function: ease-in;   /* slow start */
animation-timing-function: ease-out;  /* slow end */
animation-timing-function: steps(5);  /* jumpy */

ease
ease-in

steps(5)

3. animation-delay + animation-iteration-count

Waits 1s, then plays 3 times. Use infinite to loop forever.

.box {
  animation-name: slide;
  animation-duration: 1s;
  animation-delay: 1s;
  animation-iteration-count: 3;
}

4. animation-direction

With 3 iterations: normal jumps back to the start each time; alternate goes back and forth; reverse plays the keyframes backwards.

animation-direction: normal;
animation-direction: alternate;
animation-direction: reverse;
normal
alternate
reverse

5. animation-fill-mode

What does the element look like before the animation starts (during the delay) and after it ends? All rows have a 1s delay.

animation-fill-mode: none;      /* snaps back */
animation-fill-mode: forwards;  /* keeps end state */
animation-fill-mode: backwards; /* uses the first
   keyframe during the delay */
none
forwards
backwards

6. animation-play-state

Pause and resume an animation from JavaScript by switching this one property.

.box { animation: slide 3s linear
              infinite alternate;
       animation-play-state: paused; }
.playing .box {
  animation-play-state: running; }

7. Shorthand + multiple animations

Shorthand order: name duration timing-function delay iteration-count direction fill-mode. Separate several animations with commas.

.box {
  animation:
    slide 2s ease-in-out,
    colorChange 2s linear,
    spin 2s linear;
  animation-fill-mode: forwards;
}

⚠️ Two animations can't both animate transform: the later one wins. Here, spin uses the separate rotate property so it works alongside the slide.

8. Percentage keyframes

Use 0% to 100% for more than two steps.

@keyframes bounce {
  0%   { transform: translateY(0); }
  30%  { transform: translateY(-30px); }
  60%  { transform: translateY(0); }
  80%  { transform: translateY(-12px); }
  100% { transform: translateY(0); }
}

9. Common mistakes

transform: deg(220deg);    /* ✗ not a function: invalid, ignored */
transform: rotate(220deg); /* ✓ */

.box { animation: slide 1s; }  /* ✓ needs a duration: default is 0s,
                                  so nothing visible happens without one */

Also: an empty/auto-sized .box is hard to see. Always give the animated element a width, height and colour.
